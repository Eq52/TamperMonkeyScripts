# GitHub Chinese Translation - GITHUB汉化

## 简述

该脚本的目的是汉化GitHub，应用该脚本后可达到使GitHub部分英文转换为中文的效果。

目前，汉化还再进行中，GitHub仍有大量区域未被汉化，作者有空就继续...

---

- 将 GitHub 界面翻译为中文（Dashboard / 导航 / 搜索 / 筛选 / 仓库 / 页脚）

- AI翻译+人类翻译
